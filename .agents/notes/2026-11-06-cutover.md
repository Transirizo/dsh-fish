# Note: 生产切换（旧版 → V3.2，2026-11-06）

- ID: note-2026-11-06-cutover
- 模块: 部署
- 状态: active

## 操作（用户选 Path A：在现有 web profile 内切换）

1. `set_plugin include:dsh-fish enabled=false` → 停用旧版 dsh-fish v0.8.8。
2. `set_plugin include:dsh-fish-v3 enabled=true` → 启用 V3.2。
3. 两者均 `application: applied`、无 warnings。

## 验证证据

- `curl http://127.0.0.1:3080/dsh-fish-v3/health` → `{"ok":true,"plugin":"dsh-fish-v3","version":"3.2.0",...,"memoryCount":3,...}`（web profile 的健康路由已上线）。
- `Tool.listTools`：`fish_status/fish_recall/fish_remember/fish_diary/fish_interest/fish_browse` 6 工具在列；旧版 `her_*`/`bili_*` 工具全部消失。

## 影响与回滚

- `web` profile（dsh.example.com）现在跑 V3.2 大肥鱼；旧版 identity/tools/scheduler 已卸载。
- 旧版数据目录（`~/.dsh-fish`）**未删除**，完整保留；回滚 = 重新启用 `include:dsh-fish`（并停用 V3.2）。
- `dsh-astrbot-relay` 未动：其 QQ 会话映射继续有效，会话现在注入 V3.2 身份段（deployment-wide）。
- **隔离注意**：V3.2 身份段是 deployment-wide，`web` 里所有会话（含本工程会话、relay 的 QQ 会话）都会注入
  `dafeyu:identity`/`dafeyu:policy`。严格工程/聊天隔离需独立 profile（规格 §10），本次为单 profile 现实权衡。
