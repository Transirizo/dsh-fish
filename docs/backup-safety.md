# 记忆快照恢复安全边界

当前为memory.jsonl的有界快照，不是完整实例迁移或在线一致性快照。创建前应由管理员静默源写入。

## 已实现

- 版本化manifest v1，严格只允许memory.jsonl；16MiB文件和64KiB清单上限。
- 单次读取缓冲区计算记录数、大小和校验和，再写快照，避免拷贝和校验读取不同内容。
- 文件O_NOFOLLOW、目录链拒绝符号链接；运行目录700、文件600。
- 恢复在目标创建前校验所有数据，拒绝坏JSONL、损坏校验和、不兼容版本及路径穿越。
- 目标不同数据或无关文件一律拒绝覆盖；相同字节恢复幂等，使用wx避免意外替换。

## 验证

103个单测全过；新增路径清单篡改、损坏源与目标保留、不同记忆不覆盖、目录符号链接拒绝、不兼容manifest拒绝。

## 未交付

完整迁移还须覆盖身份、会话日志、入站账本、任务、删除记录、授权范围和部署ID等；当前清单显式列出这些排除项。
没有加密私有数据包或off-host传输验收，不允许据此进行真实数据外传。
目录替换竞态在同用户恶意进程下仍需OS权限隔离；该代码不是对共享可写主机的完整防御。
新版manifest拒绝旧版无version清单，不会静默转换或覆盖；旧档案需隔离检查后另写受控转换工具。
