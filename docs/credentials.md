# 入站凭据：原生DSH引用

## 当前源码

- 配置只设置 ingressCredentialRef，默认 DSH_FISH_INGRESS_TOKEN；仅接受 DSH_FISH_ 前缀引用，不能引用模型提供方等无关凭据。
- /say每次请求调用原生credentials.resolve(ref)，不缓存值。值缺失、解析失败、长度不在32–512字节时鉴权拒绝。
- 旧ingressToken字段为兼容读取配置而保留，标记secret，不再参与鉴权。旧值没有被自动复制到其他地方或输出；管理员完成受控迁移后应清除。
- 模型工具没有凭据写入/读取接口。配置引用不是平台授权。

## 管理配置

通过DSH原生凭据管理入口设置引用值（不把值粘贴到聊天、代码、命令行参数或Git）。若当前UI不支持该引用的设置，需要补宿主控制面配置，不能假装本插件页面已经具备该能力。

## 验证

单测覆盖每次解析、轮换、不相关引用拒绝、缺失/故障/长度限制。隔离真实DSH测试使用仅该测试进程环境中的合成凭据；覆盖层不含秘密值，测试日志不输出凭据。

## 部署风险

生产旧配置只含ingressToken时，新代码加载后/say将拒绝而不是继续使用旧密钥。需先完成原生凭据配置再验收；当前真实平台仍不允许启用。
