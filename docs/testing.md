# 测试

## 验证分层（规格 §13）

| 层 | 内容 | 状态 |
|---|---|---|
| 单元 | 规则/状态机/身份段/策略段/记忆/guard/去重 | 进行中 |
| 集成 | 真实模块 + 已配置接口契约 | 计划中 |
| 模拟端到端 | 事件 ingress → 桥 → 模型接口 → 持久化 → 出站代理 | 计划中 |
| 安全 | 工具越权/注入/SSRF/密钥/跨会话/未授权发送 | 计划中 |
| 部署 | 健康/端口/资源/重启恢复 | 计划中 |

记录：层、自动化/手工、版本、commit、环境、用例、证据、结果（PASS/FAIL/NOT RUN/BLOCKED）。

## 命令

```bash
node --test packages/dsh-fish-v3/test/
```

## 覆盖目标（P0）

- 身份/策略段：注册名、order、文本不随每日随机改写。
- 记忆：append 追加不覆盖、recall 召回、count。
- guard：秘密模式拦截、外来文本消毒。
- 投递幂等：同 eventId 不重复投递。
- 配置：默认真实发送关闭、非法值拒绝。

## 注意

- mock 事件/stub 模型/模拟出站成功**不**构成真实账号/真实 provider/生产成功（规格 §13）。
- 生成模型的自我评估不算质量证据（规格 §17）。
