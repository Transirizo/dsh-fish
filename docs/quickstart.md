# 快速开始

> 状态：**计划中**。以下命令为操作目标，未标注「可用」即不可执行。

## 三步（目标）

1. 装 DSH（已核实版本）→ 2. 装 `dsh-fish-v3` → 3. 配 provider + 明确授权平台登录/发送。

## 命令（`fish` 标签 = 操作语义，映射到 DSH/插件入口）

| 命令 | 行为 | 状态 |
|---|---|---|
| `fish install` | 预检、选版本、初始化目录/配置（不覆盖既有状态） | 计划中 |
| `fish configure` | 交互配置、校验、diff、隐藏密钥 | 计划中 |
| `fish start/stop/status` | 管理本实例、报健康 | 计划中 |
| `fish doctor` | 诊断依赖/版本/权限/磁盘/端口/配置/连通 | 计划中 |
| `fish test --offline` | 无真实账号/外部模型的模拟闭环 | 计划中 |
| `fish backup/restore` | 备份/校验、恢复进隔离目标 | 计划中 |
| `fish migrate export/import/verify` | 导出、隔离导入、校验 | 计划中 |
| `fish upgrade/rollback` | 兼容检查后的受控变更 | 计划中 |
| `fish uninstall` | 默认保留数据；删数据需另行明确授权 | 计划中 |

## 约束

- 初始化幂等；拒绝覆盖非空目录/其他实例并给出处理建议。
- 密钥不进命令行参数、shell 历史、进程列表、报告。
- 预检不擅自接管服务、静默装系统软件、开公网端口、改全局防火墙。
