# 安全

## 威胁模型

1. **提示注入**：QQ 消息、网页、附件、B 站评论、记忆、辅助模型输出都是不可信数据。
2. **SSRF**：联网抓取访问内网/云元数据/回环地址。
3. **密钥泄漏**：token/cookie/sk-/Bearer 经记忆或日志外发。
4. **跨会话越权**：一个会话读到另一会话的记忆/数据。
5. **未授权发送**：模型输出绕过发送授权直接外发。
6. **工具越权**：聊天 Agent 通过工具触碰工程写接口/部署/宿主。

## 对策

- **数据即数据**：外部文本统一过 `guard.js` 消毒；检索内容**不得**改权限、调工程指令、外泄密钥、替代审批。
- **记忆写入范围**：按 scope（私聊/群聊/全局/共享）落地；不把恶意指令当行为规则持久化。
- **发送授权**：默认真实发送关闭；发送服务在模型外强制 allowlist、类别、静默时段、冷却、每日上限、
  近似去重、失败处理、停止开关、审计。
- **工具收窄**：聊天 Agent 只挂 `fish_*`；`ctx.tools.restrict` 收窄 + `ctx.tools.guard` 拒绝。
- **抓取代理**：仅允许策略批准的 HTTP(S) 目标/端口；拒绝内网/回环/链路本地/云元数据；校验重定向、绑定地址、
  限制请求数/体积/时长（规格 §5，P1 起实施）。
- **日志/报告脱敏**：不落密钥、私聊正文、完整凭据。
