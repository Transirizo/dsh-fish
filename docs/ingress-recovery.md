# 入站账本冲突与恢复

实现状态：合成诊断入口；不支持真实平台投递。2026-11-06。

- 事件地址由account+scene+channel+eventId确定，内容指纹包含发送者及原始正文。
- 相同地址相同内容：完成记录返回原结果；processing/unknown返回409，禁止自动重跑。
- 相同地址不同内容：409 event-id-content-conflict，不调用模型。
- 回合异常：503脱敏错误，记录unknown；进程重启后仍挂起，不盲目重试。
- 重启后完成结果继续去重；不同账号不会混淆。
- JSON null/数组/标量安全拒绝。凭据解析异常默认401。

验证：98个单测通过，其中新增内容冲突、失败不重跑、成功重启去重与账号隔离、JSON形状拒绝。

新增故障注入验证：账本临时文件写入失败时响应503、不开模型，并将入口置为拒绝态；followup异常后Agent句柄会释放。105个单测通过。该写失败模拟不是实际磁盘ENOSPC或断电演练。

未完成：账本fsync/实际磁盘写满恢复、多进程互斥与分布式单活、卸载中断竞态的完整验证。旧账本缺少fingerprint的事件默认冲突拒绝，需要人工核对，不能自动迁移为可重放事件。当前原子rename不构成断电耐久承诺。
