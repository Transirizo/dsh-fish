# 可移植性与支持矩阵

> 状态：**计划中**。未实测的项一律标「未验证」，不宣称通用兼容。

## 三类部署（规格 §28）

- 全新安装：新建身份，无历史数据。
- 同实例迁移：保留逻辑身份与必需状态。
- 模板复用：复制公开代码 + 无密钥配置，新建身份。

## 待建矩阵

OS / CPU 架构 / 容器与运行时版本 / 磁盘内存 / 网络前置 / 平台连通 / 模型能力。不同 CPU 架构需对应构建，
不复用源机二进制或运行缓存。

## 状态与资产

区分持久状态（数据库/记忆/身份/媒体/任务/投递/审计）与可重建资产（镜像/依赖缓存/临时文件）。
状态必须可定位，不得只存在容器可写层；校验恢复后的绝对路径、属主、权限。
