# 生产更新前只读预检

```bash
node packages/dsh-fish-v3/sim/doctor.mjs
node packages/dsh-fish-v3/sim/doctor.mjs /受控路径/仅本插件字段.json
```

只检查版本、必要插件文件与本插件配置JSON。不会读取全profile、列举凭据、读生产会话或更改运行状态。配置失败输出字段名，不输出值或原始schema异常。

已验证DSH为0.2.2-rc.1；Node测试基线24.22.2（诊断仅接受24.9及以上24.x）。其他版本不宣称兼容。CLI失败返回非零。

## 本次实跑

Node/DSH、八个必要发布文件、默认配置检查全部PASS；缺少显式凭据引用给出WARN。单测112/112通过，包括未知字段、危险开关、秘密不回显和未验证版本拒绝。

## 不能替代的验收

此工具不是完整doctor：不检测主机权限、容器挂载、防火墙、平台可达性、账单、备份离机状态。输出这些项为NOT RUN，不以文件存在替代能力已可用。

## 生产更新顺序

1. 只读确认有效配置兼容；把旧明文入口凭据迁移到DSH凭据管理，不在聊天发送值。
2. 保留已验证源码/配置恢复点；检查数据schema与旧版本兼容，不承诺镜像回滚等于数据回滚。
3. 在独立诊断profile跑native-dsh脚本，合成回合PASS后再计划当前GUI统一重启/重载。
4. 生效后核对GUI、局部身份、五工具、健康与未授权入口拒绝，真实平台保持关闭。
