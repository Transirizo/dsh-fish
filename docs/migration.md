# 迁移与回滚

> 状态：**计划中**（P0 先做冷迁移 + 明确维护窗口）。规格 §30–31 为权威。

## 阶段（规格 §30）

1. 预检与授权 → 2. 静默与快照 → 3. 传输 → 4. 副作用关闭的恢复 → 5. 校验 → 6. 切流 → 7. 观察收尾。

## 单活发送者（规格 §31）

- 只有一个部署持有某身份/平台账号的有效投递与调度权；用部署围栏/外部租约/源关闭+凭据吊销保证源不复活。
- 目标恢复**不**自动登录/消费事件/启用投递。源审批记录是审计，不是目标侧无条件授权。
- 切流前定失败触发与回滚期限；已外发的消息不可数据库回滚，保留投递证据并防重复。
